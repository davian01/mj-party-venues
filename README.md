# MJ's party venues

A one-page comparison of venues for MJ's birthday on Saturday, Dec 19, 2026. Served by GitHub Pages from `index.html`.

`index.html` is generated, so don't edit it by hand. Edit the working copy, then rebuild:

```bash
python build.py <path to mj-venues.html>
```

The build makes three changes for the public copy: it renames the "Your favourite" labels to "Top pick", drops the pointer to the private notes file, and adds a `noindex` tag so search engines skip the page.
